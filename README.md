# E-commerce de Camisas Vintage de Futebol

Projeto desenvolvido para a disciplina de Engenharia de Software.

## Objetivo

Desenvolver um sistema de e-commerce para venda de camisas vintage de times de futebol.

## Tecnologias previstas

- Front-end: React
- Back-end: FastAPI
- Banco de Dados: PostgreSQL
